## Introduction

The most important finding from the ego [depletion debate]({{ 'depletion-debate/' | relative_url }}) is not that researchers proved [willpower]({{ 'willpower/' | relative_url }}) does not exist. It is that the largest and most carefully planned replication projects found either no clear ego-depletion effect or only very small effects. That result matters for self-improvement because many popular recommendations were built on the assumption that self-control is a limited resource that predictably runs out after use. When researchers tested that claim across dozens of laboratories using preregistered methods and thousands of participants, the evidence became much weaker than the original literature had suggested. <span class="citation-chip-wrap"><a class="citation-chip" href="https://pubmed.ncbi.nlm.nih.gov/27474142/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">A Multilab Preregistered Replication of the Ego-Depletion...by MS Hagger · 2016 · Cited by 1461 — Meta-analysis of the studies rev...</span></span></span>

## The 2016 multilab replication result

The turning point came in 2016 with a Registered Replication Report led by Martin Hagger and colleagues. Twenty-three laboratories across multiple countries followed the same preregistered protocol and tested a total of 2,141 participants. The goal was simple: use a standard ego-depletion procedure and see whether people performed worse on a subsequent self-control task. <span class="citation-chip-wrap"><a class="citation-chip" href="https://pubmed.ncbi.nlm.nih.gov/27474142/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">A Multilab Preregistered Replication of the Ego-Depletion...by MS Hagger · 2016 · Cited by 1461 — Meta-analysis of the studies rev...</span></span></span>

The result was strikingly small. The combined effect size was d = 0.04, and the confidence interval included zero. In practical terms, the study did not find convincing evidence that the experimental manipulation reliably reduced later self-control performance. <span class="citation-chip-wrap"><a class="citation-chip" href="https://pubmed.ncbi.nlm.nih.gov/27474142/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">A Multilab Preregistered Replication of the Ego-Depletion...by MS Hagger · 2016 · Cited by 1461 — Meta-analysis of the studies rev...</span></span></span> <span class="citation-chip-wrap"><a class="citation-chip" href="https://journals.sagepub.com/doi/10.1177/1745691616652873" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: journals.sagepub.com">[Sage Journals]</a><span class="citation-popover" role="note"><span class="citation-popover-source">journals.sagepub.com</span><span class="citation-popover-snippet">Sage JournalsA Multilab Preregistered Replication of the Ego-Depletion...by MS Hagger · 2016 · Cited by 1463 — Meta-analysis of the stud...</span></span></span>

This mattered because the project addressed several criticisms that often affect psychological findings:

* The methods were preregistered before data collection.
* Many independent laboratories participated.
* The sample size was far larger than most earlier studies.
* The same protocol was used across sites, reducing flexibility in analysis. <span class="citation-chip-wrap"><a class="citation-chip" href="https://pubmed.ncbi.nlm.nih.gov/27474142/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">A Multilab Preregistered Replication of the Ego-Depletion...by MS Hagger · 2016 · Cited by 1461 — Meta-analysis of the studies rev...</span></span></span>

The replication did not prove that [ego depletion]({{ 'ego-depletion/' | relative_url }}) is impossible. Instead, it showed that one widely used version of the effect could not be reproduced at a meaningful level when tested under highly controlled conditions. That finding immediately shifted the burden of proof. Supporters of the theory increasingly had to explain why strong effects had appeared in earlier studies but not in the large replication. <span class="citation-chip-wrap"><a class="citation-chip" href="https://www.psychologicalscience.org/news/releases/replication-project-investigates-self-control-as-limited-resource.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: psychologicalscience.org">[Association for Psychological Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">psychologicalscience.org</span><span class="citation-popover-title">replication project investigates self control as limited resource</span><span class="citation-popover-snippet">Association for Psychological ScienceReplication Project Investigates Self-Control as Limited...29 Jul 2016 — A new research replication...</span></span></span> <span class="citation-chip-wrap"><a class="citation-chip" href="https://www.psychologicalscience.org/news/releases/replication-project-investigates-self-control-as-limited-resource.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: psychologicalscience.org">[Association for Psychological Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">psychologicalscience.org</span><span class="citation-popover-title">replication project investigates self control as limited resource</span><span class="citation-popover-snippet">Association for Psychological ScienceReplication Project Investigates Self-Control as Limited...29 Jul 2016 — A new research replication...</span></span></span>

### Why supporters were not fully convinced

Advocates of ego depletion argued that the replication may have used a weak depletion task. Some researchers claimed the procedure failed to create enough self-control demand to produce the effect in the first place. Others suggested that the specific tasks chosen did not capture the broader theory adequately. <span class="citation-chip-wrap"><a class="citation-chip" href="https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2016.01155/full" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: frontiersin.org">[Frontiers]</a><span class="citation-popover" role="note"><span class="citation-popover-source">frontiersin.org</span><span class="citation-popover-snippet">FrontiersA Multilab Preregistered Replication of the Ego-Depletion...by J Dang · 2016 · Cited by 109 — The ego depletion effect has not...</span></span></span>

These objections kept the debate alive. Rather than ending the discussion, the 2016 project changed the question from “Does ego depletion exist?” to “Under what conditions, if any, does it appear?”

## The 2021 preregistered test result

A second major milestone arrived in 2021. Kathleen Vohs and colleagues conducted a large preregistered multisite project involving 36 laboratories and 3,531 participants. This study was partly designed to answer criticisms of the 2016 effort by using a different replication strategy. Rather than reproducing one exact experiment, laboratories used procedures intended to represent the broader ego-depletion paradigm. <span class="citation-chip-wrap"><a class="citation-chip" href="https://pubmed.ncbi.nlm.nih.gov/27474142/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">A Multilab Preregistered Replication of the Ego-Depletion...by MS Hagger · 2016 · Cited by 1461 — Meta-analysis of the studies rev...</span></span></span> <span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC12422598/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PMC]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-title">PMCA Multisite Preregistered Paradigmatic Test of the Ego</span><span class="citation-popover-snippet">by KD Vohs · 2021 · Cited by 292 — We conducted a preregistered multilaboratory project (k = 36; N = 3531) to assess the size and robu...</span></span></span>

If the 2016 failure could be blamed on one particular task, the 2021 project tested a broader set of depletion procedures. ## What small or unclear effects mean for advice

For people interested in self-improvement that works, the practical lesson is less dramatic than either side of the debate sometimes suggests.

The replication projects do not show that self-control is an illusion. People clearly experience fatigue, distraction, temptation and reduced persistence. What the studies challenge is the specific claim that a single, limited willpower resource is being predictably drained by earlier acts of self-control. <span class="citation-chip-wrap"><a class="citation-chip" href="https://pubmed.ncbi.nlm.nih.gov/27474142/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">A Multilab Preregistered Replication of the Ego-Depletion...by MS Hagger · 2016 · Cited by 1461 — Meta-analysis of the studies rev...</span></span></span>

If the true effect is near zero or very small, several common pieces of advice become less persuasive:

* Assuming every difficult decision permanently weakens later self-control.
* Treating lapses as evidence that a fixed [willpower tank]({{ 'willpower-tank/' | relative_url }}) has been emptied.
* Overemphasising conservation of willpower instead of designing better environments and habits.

By contrast, the replication findings fit more comfortably with approaches that focus on context, routines, incentives, attention management and reducing friction. If depletion effects are weak, then everyday behaviour may depend more on [motivation]({{ 'motivation/' | relative_url }}), habit strength, stress, sleep, expectations and situational cues than on a rapidly exhausted internal resource. <span class="citation-chip-wrap"><a class="citation-chip" href="https://pubmed.ncbi.nlm.nih.gov/27474142/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">A Multilab Preregistered Replication of the Ego-Depletion...by MS Hagger · 2016 · Cited by 1461 — Meta-analysis of the studies rev...</span></span></span> <span class="citation-chip-wrap"><a class="citation-chip" href="https://pubmed.ncbi.nlm.nih.gov/27474142/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">A Multilab Preregistered Replication of the Ego-Depletion...by MS Hagger · 2016 · Cited by 1461 — Meta-analysis of the studies rev...</span></span></span>

The major replication projects therefore did not merely question one psychological theory. They changed the standard of evidence for self-control advice. After studies involving thousands of participants across dozens of laboratories, the safest conclusion is that any ego-depletion effect appears much smaller and less reliable than the classic version of the theory suggested. <span class="citation-chip-wrap"><a class="citation-chip" href="https://pubmed.ncbi.nlm.nih.gov/27474142/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">A Multilab Preregistered Replication of the Ego-Depletion...by MS Hagger · 2016 · Cited by 1461 — Meta-analysis of the studies rev...</span></span></span> <span class="citation-chip-wrap"><a class="citation-chip" href="https://pubmed.ncbi.nlm.nih.gov/27474142/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">A Multilab Preregistered Replication of the Ego-Depletion...by MS Hagger · 2016 · Cited by 1461 — Meta-analysis of the studies rev...</span></span></span>

      panels.forEach(function (panel) {
        var active = panel.getAttribute('data-ebay-market-panel') === marketId;
        panel.hidden = !active;
      });
      if (available.indexOf(marketId) >= 0) select.value = marketId;
      var option = select.options[select.selectedIndex];
      Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
        label.textContent = option ? option.text : marketId;
      });
      Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
        flag.className = flagClass(marketId);
      });
      Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
        label.textContent = option ? option.text : marketId;
      });
      Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
      });
      if (persist) {
        try {
          if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId);
        } catch (err) {}
      }
      closeMenu(section);
    }
    select.addEventListener('change', function () {
      selectMarket(select.value, true);
    });
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          selectMarket(button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    selectMarket(inferMarket(available), false);
  });
})();
